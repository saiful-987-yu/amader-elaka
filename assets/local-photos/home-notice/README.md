# Home-Page Notice Background Photo (local, bundled with the site)

Put one photo here to use it as the background of the notice box(es) in the
"Notices & News" section on the home page (the ones written in
`window.HOME_NOTICES` in `assets/home-content/home-content.js`).

| Filename | What it's for |
|---|---|
| `notice-bg.jpg` | Background picture behind every home-page notice card |

- The file name must be exactly `notice-bg.jpg`.
- A dark layer is added over the photo automatically and the text turns white, so any photo stays readable.
- No file here = notices keep their normal plain background, exactly as before.
- It is used only on the home page; the category notices (`CATEGORY_NOTICES`) are not affected.

Drop the file in and push to GitHub: no code change and no backend work.
